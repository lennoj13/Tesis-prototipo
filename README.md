# Plataforma Web de Matching Bidireccional

**Prácticas Preprofesionales — Universidad de Guayaquil**

Plataforma web de matching bidireccional basada en técnicas NLP y modelos de similitud semántica para optimizar el proceso de búsqueda y postulación de prácticas preprofesionales.

## Stack Tecnológico

- **Frontend:** Next.js (React)
- **Backend:** Python + Flask
- **Motor NLP:** SBERT + Similitud del Coseno
- **Base de Datos:** PostgreSQL

## Estructura

```
frontend/    → Interfaz web (Next.js)
backend/     → API RESTful (Flask)
nlp_engine/  → Motor de matching semántico (Python)
```
